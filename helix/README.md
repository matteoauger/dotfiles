## Treesitter
Import grammars : `hx --grammar fetch` and `hx --grammar build`

## Language servers
- VSCODE : `npm i --global vscode-langservers-extracted`
- RUST : `rustup component install rust-analyzer`
- DOTNET : [csharp-language-server](https://github.com/razzmatazz/csharp-language-server)

## Formatters
- Prettier : `npm i --global prettier`
- Csharpier : `dotnet tool --global install csharpier`
